# 交接包

这是“小镇做题家”的轻量续接包，不替代源码、部署日志或 Chrome Web Store 控制台。

推荐阅读顺序：

1. [`PROJECT_CONTEXT.md`](../../PROJECT_CONTEXT.md)：当前产品、运行状态、部署入口、验证边界与风险的事实源。
2. [`CHANGELOG.md`](CHANGELOG.md)：只追加的重要变更、决策与未验证项。
3. 相关代码和测试：从 `PROJECT_CONTEXT.md` 的“关键入口”进入。

`README.md` 与 `docs/CODEX_HANDOFF.md` 是早期背景资料，部分运行配置已过时；遇到冲突时以 `PROJECT_CONTEXT.md` 和当前代码/运行环境为准。

维护原则：记录结论和证据边界，不记录密钥、令牌、私有密钥或可复制的用户数据。
