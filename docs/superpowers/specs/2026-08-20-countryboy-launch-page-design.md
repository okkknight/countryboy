# 小镇做题家落地页设计

## 目标

为“小镇做题家”提供一张公开访问的静态落地页，让访客理解插件用途、下载 ZIP 安装包，并完成 Chrome 的“加载已解压的扩展程序”安装流程。页面不承诺或伪装一键安装，不包含 Chrome Web Store 分发。

核心文案：**小镇做题家，看谁先卷死谁。**

## 受众与边界

- 面向使用桌面版 Chrome 的个人用户。
- 插件把当前页面可见区域截图提交给后端，识别清晰题目并给出答案或兜底提示。
- ZIP 下载包只含 `extension/` 目录的可加载文件；不携带 Gemini 密钥、后端 `.env`、开发缓存或测试文件。
- 页面只提供下载与指导，不采集账号、联系方式、截图或答题历史。
- 普通 macOS / Windows 用户不能从自托管网站自动安装 Chrome 插件；页面明确说明需手动加载。

## 信息架构与文案

1. **页首**：文字标识“小镇做题家”、跳转到安装说明的导航链接。
2. **Hero**：左侧 slogan、功能说明和“下载插件 ZIP”主按钮；右侧为超大彩虹渐变“卷”字。使用红笔批注与成绩栏作为戏谑点缀，但不干扰信息层级。
3. **使用方式**：三项短说明：截图题目、识别题型、给出答案与解析。明确不可辨识时会提示重新截图，而非强答。
4. **安装指南**：三步：下载并解压 ZIP、打开 `chrome://extensions`、开启开发者模式后点击“加载已解压的扩展程序”并选择解压目录。每步都带可读文字和简洁图标。
5. **边界说明**：只上传用户主动触发的当前可见截图；模型密钥仅在服务端；不保证模糊或缺题截图的答案。
6. **收尾 CTA**：再次提供下载按钮及安装指南锚点，文案保持自嘲、不过度承诺。

## 视觉系统

- 背景严格使用白色，文字以近黑色呈现；仅“卷”字使用彩虹渐变。
- 字体：中文无衬线粗体标题 + 易读正文；硬朗方正，避免企业 SaaS 风格。
- 布局：开放留白、黑色水平线与试卷格线；不使用玻璃拟态、深色背景、圆角卡片网格。
- 戏谑元素：少量红色手写批注、下划线、勾选符号、编号与卷王印章；均为 CSS/SVG 装饰，支持减少动态效果偏好。
- 响应式：桌面 hero 双栏；小屏依次显示文案、卷字、按钮，安装三步纵向排列；无横向溢出。

## 交互与数据流

- “下载插件 ZIP”链接到同源静态文件 `/countryboy/downloads/countryboy-extension.zip`，使用 `download` 属性。
- “查看安装步骤”滚动至安装锚点。
- 页首导航和页尾 CTA 重用相同下载与锚点链接。
- 页面本身没有 API 调用、表单、追踪脚本或 Cookie 依赖。

## 部署架构

- 新增静态站点源目录 `launch-page/`，无需 Node 构建步骤：HTML、CSS、少量原生 JavaScript、SVG/PNG 图标和发布脚本。
- 发布产物部署到 VPS `/opt/boringmax/countryboy/site`，归属现有低权限 `shipnow` 用户。
- 由 Caddy 的 `boringmax.com` 站点处理 `/countryboy`：重写为 `/countryboy/`，静态根指向上述目录，不影响现有站点路由。
- 下载包部署在站点目录的 `downloads/` 子目录，Caddy 以 `application/zip` 提供，并禁止缓存以便用户获得最新版本。
- 插件后端继续独立通过 `https://api.boringmax.com/countryboy` 提供服务；落地页不暴露或依赖 Gemini 密钥。

## 错误处理与可用性

- ZIP 不存在或网络失败时，浏览器将显示普通下载失败；页面提供“重新下载”与安装步骤，不伪造安装成功状态。
- 页面在不支持平滑滚动或禁用 JavaScript 时仍可通过原生锚点和普通链接使用。
- 使用语义化标题、按钮/链接可聚焦样式、足够对比度和 `prefers-reduced-motion`。

## 验证

1. 本地静态服务器下检查 HTML、链接、ZIP 内容和手机/桌面布局。
2. 通过浏览器查看 1440px 宽和 390px 宽页面，确认 CTA、Slogan、安装三步和卷字不溢出。
3. 在 VPS 上验证 Caddy 配置、`https://boringmax.com/countryboy/`、ZIP 下载 HTTP 状态和压缩包可解压。
4. 检查 ZIP 的根目录包含 `manifest.json`，且不含 `.env`、`.venv`、`backend/` 或密钥。
5. 与已确认概念图逐项比对：白底、黑色试卷结构、彩虹卷字、红笔批注、首屏 CTA、三步指南和移动端结构。
